业务 tool = CLI 包 schema

跟 Bash 一样 · 就是多了类型

{
  "name": "nf_tts_synth",
  "description": "生成 TTS 语音 · 支持晓晓/云希/云扬 voice",
  "input_schema": {
    "type": "object",
    "properties": {
      "text": { "type": "string" },
      "voice": { "enum": ["xiaoxiao", "yunxi", "yunyang"] },
      "out_path": { "type": "string" }
    },
    "required": ["text", "voice", "out_path"]
  }
}

# 执行: 跟 Bash 一样 · subprocess.run
def nf_tts_synth(args):
    return subprocess.run([
      "nf-tts", "synth",
      "--text", args["text"],
      "--voice", args["voice"],
      "--out", args["out_path"],
    ], capture_output=True)

# NextFrame agent v1 骨架 · ~200 行

# 1. 5 基础 tool(抄 Claude Code)
TOOLS = [bash_tool, read_tool, write_tool, glob_tool, grep_tool]

# 2. 业务 tool(NextFrame CLI 包装 · 每个 ~20 行)
TOOLS += [nf_tts_synth, nf_ffmpeg_cut, nf_whisperx, ...]

# 3. 主循环(抄 Claude Code query.ts)
messages = [{"role": "user", "content": task}]
while True:
    resp = call_llm(
      model="Pro/MiniMaxAI/MiniMax-M2.5",   # 硅基 · OpenAI compat
      messages=messages,
      tools=TOOLS,
    )
    if not resp.tool_uses:
        break
    for tu in resp.tool_uses:
        result = dispatch(tu)     # 就 execute · 不 gate
        messages.append({"role": "tool", "content": result})
依赖:只需 OpenAI Python SDK(兼容硅基 base_url)+ subprocess。
