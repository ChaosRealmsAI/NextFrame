第 2 条

CLI 驱动

整个产品命令行化 · 桌面端只是 UI 外壳
# 全流程 CLI · 人 / AI / CI 走同一代码路径
$ cc chat "30s 产品介绍视频" → AI 输出 JSON
$ nf build project.json → 解析 + 预渲染
$ nf preview project.json → 桌面端弹出
$ nf export project.json -o out.mp4 → 4K MP4 导出
第 3 条

frame pure

核心架构不变式 · 同一 t 永远同一像素
frame(t, json) = pixels

❌ 反面

第 1 次 render 这一帧是 A 色 · 第 2 次变 B 色 · 播放抖 · 录屏乱 · 调试崩溃

✅ frame pure

t=3.7s 喂进去 永远是同一张像素 · 预览 / 编辑 / 录制 / CI 都对得上
实现代价: 禁 Date.now() 直接用 · 禁未 seeded 的 Math.random() · 禁未缓存的网络
第 4 条

3 模式像素级一致

play · preview · export 三模式同一帧必须像素相同
▶️

play

用户点播放
✏️

preview

编辑器里看
🎬

export

导出 MP4
pixels(play) == pixels(preview) == pixels(export)
常见坑: preview 正常 / export 黑屏 / 颜色错 / 帧错位 —— 都因为三模式没从地基对齐 · v0.1 起防死
第 5 条

桌面端是预览 + 可选编辑

不是主操作入口 · 人可跳过 · CLI 也能跑完

✅ 桌面端该做

• 可视化 JSON → 视频
• 多轨道展示
• 改 clip 位置(拖拽)
• 改时间范围 (in/out)
• 导出按钮

❌ 桌面端不该做

• 内置 AI 对话框
• 复杂剪辑 (Premiere 那种)
• 模板市场 / 素材库
• 资产管理中心
• 账号 / 登录

声明时间锚点 · 轨道正负加减 · 改一个 · 全局跟着走

  "anchors": { "intro-end": 5.0, "feat-1-end": 12.0, "feat-2-end": 30.0 },
  "tracks": [{
    "clips": [
      { "start": "0", "end": "intro-end" }, // 片段 A
      { "start": "intro-end - 0.5", "end": "feat-1-end + 0.3" }, // 片段 B · 用偏移
      { "start": "feat-1-end", "duration": "feat-2-end - feat-1-end" }
    ]
  }]
}
