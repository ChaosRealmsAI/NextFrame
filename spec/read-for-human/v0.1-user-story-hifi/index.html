step 1 · 提需求

一句话给 Claude Code

# Claude Code 聊天窗口
> 帮我做个 60 秒产品介绍视频 讲 NextFrame 的三个核心功能
AI · Claude Opus 4.7
收到 · 我去读产品文档 · 写一份 NextFrame JSON 给你...
💭 无模板选择 · 无下拉菜单 · 无表单填写 · 就一句话
step 2 · 生成 JSON

Claude Code 写 project.json

// project.json · NextFrame 视频描述
{
  "duration": 60, // 秒
  "fps": 60,
  "resolution": [3840, 2160], // 4K
  "tracks": [
    { "type": "scene", "clips": [/* 3 段产品介绍 */] },
    { "type": "text", "clips": [/* 字幕 */] },
    { "type": "audio", "clips": [/* 配乐 */] },
    { "type": "transition", "clips": [/* 转场 */] }
  ]
}
💾 JSON 是 单一真理源 · 桌面端 / CLI / runtime 全从这里派生
