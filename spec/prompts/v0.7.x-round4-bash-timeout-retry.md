## 背景

Round 2 DeepSeek 真跑发现 3 个通用问题:
1. **Bash tool 无 timeout** · whisperx 首次下 align model 挂 15 min 才被人工 kill · agent 期间完全无响应
2. **provider 429 无 retry** · SiliconFlow TPM 到顶直接报错 · runner exit 2 · agent 半路挂
3. **tool failure model 乱来** · whisperx 挂后 DeepSeek 凭记忆手写 transcript(不escalate 不报错)

## 目标(通用 · Claude Code 风)

1. **Bash tool timeout**:默认 120s · per-call 可覆盖 · 超时 SIGKILL + 返回 `{"ok":false,"timed_out":true,"elapsed_sec":N}`
2. **provider 429 / 5xx / transient 自动 retry**:exponential backoff 1s → 2s → 4s · max 5 次 · log::warn 每次
3. **stats 新增 `retries_by_status: HashMap<u16, u32>`** 统计每类错误重试次数
4. **config 新字段**:`bash_timeout_sec`(默认 120)· `provider_max_retries`(默认 5)· `provider_retry_base_ms`(默认 1000)

### 1. `crates/nf-agent/src/tool.rs`

`BashTool::call`:
```rust
// 当前用 tokio::process::Command · 加 tokio::time::timeout 包
let timeout_sec = args.get("timeout_sec").and_then(Value::as_u64).unwrap_or(self.default_timeout_sec);
let output = match tokio::time::timeout(
    Duration::from_secs(timeout_sec),
    cmd.output(),
).await {
    Ok(Ok(o)) => o,
    Ok(Err(e)) => return Err(anyhow!("bash spawn: {e}")),
    Err(_) => {
        // SIGKILL via child handle · 或直接返 err

            "ok": false,
            "timed_out": true,
            "timeout_sec": timeout_sec,
            "command": cmd_str,
        }));
    }
};
```

### 2. `crates/nf-agent/src/provider.rs`

`OpenAiCompat::chat` 包一层 retry loop:
```rust
let mut attempt = 0;
loop {
    match self.chat_once(...).await {
        Ok(r) => return Ok(r),
        Err(e) => {
            let status = extract_http_status(&e);  // regex 扫 "returned XXX"
            let retryable = matches!(status, Some(429) | Some(500..=599));
            if retryable && attempt < self.max_retries {
                attempt += 1;
                self.stats.lock()?.retries_by_status.entry(status.unwrap_or(0)).and_modify(|c| *c += 1).or_insert(1);
                let wait_ms = self.retry_base_ms * (1 << (attempt - 1).min(5));  // 1s 2s 4s 8s 16s
                log::warn!("provider {status:?} retry {attempt}/{max} after {wait_ms}ms");
                tokio::time::sleep(Duration::from_millis(wait_ms)).await;
                continue;
            }
            return Err(e);
        }
    }
}
```

`OpenAiCompat` 结构加 `retries_by_status: Arc<Mutex<HashMap<u16, u32>>>` · `max_retries: usize` · `retry_base_ms: u64`。
