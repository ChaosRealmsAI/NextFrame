## 背景

Round 1 分析:MiniMax 单跑 $0.31 · 15 iters 空跑 · 无成本保护。model 乱想可无限烧钱。Claude Code 有 cost warning + hard stop。engine 需要同等能力。

## 目标(通用 · 配置驱动)

1. **每轮末估算累积 cost** · 用 config.pricing + stats · 得 `cumulative_cost_usd`
2. **warn 阈值**:默认 $0.10 · 首次超过 log::warn 一次(不反复 spam)
3. **hard stop 阈值**:默认 $0.50 · 超过立即 break loop · AgentResult 带 `exceeded_budget: true` + `budget_hit_usd`
4. **config**:
   ```toml
   [cost_guard]
   warn_usd = 0.10
   hard_stop_usd = 0.50
   ```
5. **stats 新增** `peak_cost_usd: f64`(max 观测值)

## 变动文件

### 1. `crates/nf-agent/src/config.rs`

```rust
#[serde(default)]
pub cost_guard: CostGuardConfig,

#[derive(Debug, Clone, Deserialize)]
pub struct CostGuardConfig {
    #[serde(default = "default_warn_usd")]
    pub warn_usd: f64,
    #[serde(default = "default_hard_stop_usd")]
    pub hard_stop_usd: f64,
}

impl Default for CostGuardConfig {
    fn default() -> Self {
        Self { warn_usd: 0.10, hard_stop_usd: 0.50 }
    }
}

fn default_warn_usd() -> f64 { 0.10 }
fn default_hard_stop_usd() -> f64 { 0.50 }
```

### 2. `crates/nf-agent/src/agent.rs`

`run()` 循环里每轮 chat 后:

```rust
let cost = self.config.estimate_cost_usd(&stats);
if !warned && cost >= self.config.cost_guard.warn_usd {
    log::warn!("cost warning: ${cost:.4} >= ${}(warn threshold)", self.config.cost_guard.warn_usd);
    warned = true;
}
if cost >= self.config.cost_guard.hard_stop_usd {
    log::error!("cost hard stop: ${cost:.4} >= ${}", self.config.cost_guard.hard_stop_usd);
    return Ok(AgentResult {
        completed: false,
        iters: iter + 1,
        stats,
        final_text: None,
        forced_stop_missing_outputs: Vec::new(),
        exceeded_budget: true,
        budget_hit_usd: Some(cost),
        // ... other fields
    });
}
```

AgentResult 扩字段 `exceeded_budget: bool` + `budget_hit_usd: Option<f64>`。

### 3. `crates/nf-agent/src/bin/nf-agent.rs`

stats log 加输出 `exceeded_budget=...` `budget_hit_usd=...`。

### 4. `crates/nf-agent/tests/cost_guard.rs`(新)

MockProvider 每次返回 Usage 大 token 数模拟烧钱:

- `warn_threshold_logged_once`:MockProvider 返 Usage 10k tokens/轮 · pricing [$10/M, $10/M] → 0.2 usd/iter · 第 1 轮就超 $0.10 warn · 后续不再 warn
- `hard_stop_kicks_in`:pricing [$100/M, $100/M] → 2 usd/iter · 1 轮即超 $0.50 · AgentResult.exceeded_budget=true
