## CLI 接口

```
nf-agent <task> [--config PATH] [--skills-dir PATH] [--max-iters N] [--log PATH]

参数:
  <task>               必填 · 用户给 agent 的目标
  --config PATH        config.toml · 默认 ./nf-agent.toml
  --skills-dir PATH    skill md 目录 · 默认 ./skills · 递归扫 */SKILL.md
  --max-iters N        最大循环轮数 · 默认 20
  --log PATH           log 输出路径 · 默认 stderr

退出码:
  0 = agent FINAL(不调 tool 的 assistant message)
  1 = max_iters 用尽
  2 = 错误(API / config / 权限)
```

## Skill 格式(外置 md · engine 不解析内容)

`skills/<name>/SKILL.md`:
```markdown
# <name> · 一句话描述

任意 md 内容 · 告诉 agent 该做啥 · engine 只读文件 · 返给 agent。
```

**engine 行为**:
- 启动扫 `--skills-dir` 下每个子目录的 `SKILL.md`
- 从每个 SKILL.md 第一行 `# <name> · <desc>` 提取 name + desc 作 enum 值
- `load_skill` tool schema 的 enum 动态生成
- `load_skill(name="clips")` 返回 `clips/SKILL.md` 的全文

## Tool trait(lib.rs)

```rust
pub trait Tool {
    fn name(&self) -> &str;
    fn description(&self) -> &str;
    fn input_schema(&self) -> serde_json::Value;
    async fn call(&self, args: serde_json::Value) -> Result<serde_json::Value>;
}
```

### 3 个 builtin tool

1. **Bash**:`bash -c <command>` · capture stdout/stderr/exit_code · 所有输出强制转 String(errors=replace · 避免 bytes bug)· 默认 30s timeout
2. **Read**:读文件 · 最大 10_000 字符 · UTF-8 replace
3. **LoadSkill**:从 SkillRegistry 查 name · 返 md 全文(enum 动态生成)

## Provider trait

```rust
pub trait LlmProvider {
    async fn chat(
        &self,
        model: &str,
        messages: &[Message],
        tools: &[serde_json::Value],
    ) -> Result<ChatResponse>;
}

pub struct ChatResponse {
    pub content: Option<String>,
    pub tool_calls: Vec<ToolCall>,
    pub usage: Usage,  // prompt_tokens / completion_tokens
}
```

### `OpenAiCompat` impl

- HTTP POST `{base_url}/chat/completions` · JSON body · `tools` 参数(OpenAI format)
- 读 `api_key_env` 对应环境变量
- 用 `reqwest` + `serde` · `async`
- 返回 parse 的 ChatResponse

## Agent loop(agent.rs)

```rust
pub struct Agent {
    provider: Box<dyn LlmProvider>,
    tools: Vec<Box<dyn Tool>>,
    skills: SkillRegistry,
    config: Config,
}

impl Agent {
    pub async fn run(&self, task: &str, max_iters: usize) -> Result<AgentResult> {
        let mut messages = vec![
            Message::system(&self.config.system_prompt),
            Message::user(task),
        ];
        let mut stats = Usage::default();

        for iter in 0..max_iters {
            let resp = self.provider.chat(&self.config.model, &messages, &self.tool_schemas()).await?;
            stats.add(&resp.usage);

            if resp.tool_calls.is_empty() {
                log::info!("FINAL: {}", resp.content.as_deref().unwrap_or(""));
                return Ok(AgentResult { completed: true, iters: iter + 1, stats, final_text: resp.content });
            }

            messages.push(Message::assistant_with_tools(resp.content, resp.tool_calls.clone()));

            for tc in &resp.tool_calls {
                log::info!("→ tool: {}({})", tc.name, tc.args);
                let result = self.dispatch(tc).await;
                log::info!("← result: {}", truncate(&serde_json::to_string(&result)?, 200));
                messages.push(Message::tool(tc.id.clone(), result));
            }
        }
        Err(anyhow!("max iters reached"))
    }
}
```
