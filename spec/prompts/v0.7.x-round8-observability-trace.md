## 背景

查 `run.log` tail 难导航 — 时间戳 · tool call · result · stats 全线性混一块。用户要求"确保生成的 clip 啥的你都知道" · 观测性是基础。

## 目标(通用)

1. **JSONL trace sidecar**:engine 每轮末 append 一行 JSON 到 `--trace FILE` 指定路径 · 结构:
   ```json
   {"t":"2026-04-21T13:20:00Z","iter":3,"event":"tool_call","name":"Bash","args":{...},"result":{...},"duration_ms":1234,"retries":0,"cost_usd":0.02,"context_bytes":15000}
   ```
   事件类型:`chat_request`, `tool_call`, `final`, `budget_hit`, `forced_stop`, `retry`
2. **CLI 参数**:`--trace PATH`(默认 None · 不写)· 或 toml `[trace] path = "..."`
3. **HTML dashboard**(静态 · 读 JSONL):
   - 路径 `crates/nf-agent/tools/trace-viewer.html`(产品内建观测工具)
   - 用户:`nf-agent --trace run.jsonl ...` 后 `open tools/trace-viewer.html?src=run.jsonl`
   - 显示 timeline:每 tool 一行 bar · 颜色编码 event · 点击展开 args/result JSON
   - 侧栏:total iters / total cost / peak context_bytes / retry 分布
   - 纯 HTML+CSS+JS · 无依赖 · 单文件 · fetch JSONL 解析

### 2. `crates/nf-agent/src/trace.rs`(新)

```rust
use serde_json::{json, Value};
use std::fs::OpenOptions;
use std::io::Write;

pub struct TraceWriter {
    path: Option<PathBuf>,
}

impl TraceWriter {
    pub fn new(path: Option<impl Into<PathBuf>>) -> Self {
        Self { path: path.map(Into::into) }
    }

    pub fn emit(&self, event: &str, data: Value) {
        let Some(path) = &self.path else { return };
        let line = json!({
            "t": chrono::Utc::now().to_rfc3339(),
            "event": event,
            ...data
        });
        if let Ok(mut f) = OpenOptions::new().create(true).append(true).open(path) {
            let _ = writeln!(f, "{}", line.to_string());
        }
    }
}
```

注意:**禁引 chrono**(最小依赖)· 用 `std::time::SystemTime` + `.duration_since(UNIX_EPOCH)` 输出 Unix ms timestamp 即可(dashboard JS 转 Date)。
