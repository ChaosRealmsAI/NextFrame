# ally gpt · Round 3 · context compaction(通用 agent loop token 预算)

**工作目录**: `/Users/Zhuanz/bigbang/NextFrame/.worktrees/autopilot-v0.7.x-64fadcea-20260421-2012`

## 背景

Round 1 跑 DeepSeek V3.2 在 translate 步 429 rate-limit:**单轮请求累积 tool result 把上下文吹到 200k+ token**。`Bash` 的 `yt-dlp` / `ffmpeg` / `whisperx` 一次产上千行日志,`Read` 大 JSON 文件也类似,都以全文形式进 message history,每轮 chat 都重发。

**通用 bug**:任何 agent loop 跑稍微多 tool 就炸。不是 DeepSeek 问题 · 是 engine 问题。

## 目标(通用 · 零业务耦合)

engine 加:
1. **单条 tool result 截断**:每个 `Message::Tool` 存入 history 前,长度超阈值(默认 4000 chars)→ 保头 + 保尾 + 中间写 `... [truncated N chars] ...`
2. **Message history soft budget**:整 history 字符超阈值(默认 200_000 chars)→ 压缩最老那批 tool result(更激进截断到 512 chars / 条)
3. **stats 新增 `context_bytes: usize`** 每轮末观测
4. **config.max_tool_result_chars / max_history_chars** 可选覆盖

**禁**: 硬编码 grep "whisperx" / "ffmpeg" 等业务关键字 · 一律字符级截断。

### 2. `crates/nf-agent/src/provider.rs`

`Message::tool` 增加 `truncate_middle` 工具函数 · 保头尾中间 placeholder:

```rust
pub fn truncate_middle(s: &str, max: usize) -> String {
    if s.len() <= max { return s.to_owned(); }
    let keep = max.saturating_sub(40) / 2;
    let head: String = s.chars().take(keep).collect();
    let tail_start = s.len().saturating_sub(keep);
    let tail: String = s.chars().skip(tail_start.min(s.chars().count())).collect();
    let truncated = s.len() - head.len() - tail.len();
    format!("{head}\n... [truncated {truncated} chars] ...\n{tail}")
}
```

调用点:`Message::tool(tool_call_id, result_json_string, max_chars)` 接 max_chars 参数 · 超了截。

### 3. `crates/nf-agent/src/agent.rs`

`Agent::run` 循环里:

```rust
// dispatch 后 · push tool message 时应用 truncate
let result_str = serde_json::to_string(&result)?;
messages.push(Message::tool(tool_call.id.clone(), &result_str, self.config.max_tool_result_chars));

// 每轮末计算 history 总字节 · 超 max_history_chars 压缩老消息
let total = estimate_history_bytes(&messages);
if total > self.config.max_history_chars {
    compact_old_tool_results(&mut messages, self.config.max_tool_result_chars / 8);
    log::info!("context compacted · bytes now = {}", estimate_history_bytes(&messages));
}
```

`compact_old_tool_results` 保留最新 3 个 tool result 不动 · 更老的进一步截到 512 chars。

## 硬约束

- ❌ 禁依赖具体 tool 名(Bash / Read / whisperx)判断是否截断 · 一律 char-len

- ❌ 禁截 system / user 消息(只截 tool result · 保留问题上下文)
