### 1. `crates/nf-agent/src/skill.rs`

加 YAML frontmatter parse:
```rust
#[derive(Debug, Clone, Deserialize, Default)]
pub struct SkillFrontmatter {
    pub name: Option<String>,
    pub description: Option<String>,
    #[serde(default)]
    pub expected_outputs: Vec<String>,  // glob patterns
}

pub struct Skill {
    pub name: String,
    pub description: String,
    pub content: String,               // 给 agent 看的 md body(frontmatter 剥掉)
    pub expected_outputs: Vec<String>, // 从 frontmatter 读
}
```

parse 逻辑:
- 文件开头 `---\n` → 到下一个 `---\n` 之间 = YAML
- 用 `serde_yaml` crate (加依赖)
- frontmatter 可选 · 没有就当空 expected_outputs

skill md 格式例:
```markdown
---
name: clips
description: 视频剪辑
expected_outputs:
  - "**/clips/index.html"
  - "**/clips/clip_*.mp4"
  - "**/clips/clip_*.translations.*.json"
---

# clips skill body 内容 ...
```

**兼容旧格式**:无 frontmatter 的 md 照常 load(name 从文件名推断 · expected_outputs 空)

### 2. `crates/nf-agent/src/tool.rs`

加 `VerifyOutputsTool` builtin:
```rust
pub struct VerifyOutputsTool {
    skills: Arc<SkillRegistry>,
    workspace: PathBuf,
}

impl Tool for VerifyOutputsTool {
    fn name(&self) -> &str { "verify_outputs" }
    fn description(&self) -> &str {
        "Verify expected outputs exist per skill. Returns present/missing lists."
    }
    fn input_schema(&self) -> Value { json!({
        "type": "object",
        "properties": { "skill": {"type": "string"} },
        "required": ["skill"]
    }) }
    async fn call(&self, args: Value) -> Result<Value> {
        let skill_name = args["skill"].as_str().context("skill required")?;
        let skill = self.skills.get(skill_name).context("skill not found")?;
        let mut present = vec![];
        let mut missing = vec![];
        for pattern in &skill.expected_outputs {
            let abs_pattern = self.workspace.join(pattern);
            let matches: Vec<_> = glob::glob(abs_pattern.to_str().unwrap_or(""))?
                .filter_map(|r| r.ok())
                .collect();
            if matches.is_empty() {
                missing.push(pattern.clone());
            } else {
                present.extend(matches.iter().map(|p| p.display().to_string()));
            }
        }
        Ok(json!({
            "skill": skill_name,
            "present": present,
            "missing": missing,
            "all_present": missing.is_empty(),
        }))
    }
}
```

需要加 `glob = "0.3"` 到 Cargo.toml。

### 3. `crates/nf-agent/src/agent.rs`

track `active_skills` (agent load_skill 过的 skill name set)· FINAL 前 check:

```rust
pub struct Agent {
    // ... existing
    active_skills: Mutex<HashSet<String>>, // 或 RefCell
}

// load_skill tool 执行成功时插入 active_skills
// (需要 tool 能通知 agent · 或把 LoadSkillTool 改成带 Agent 引用)
// 简化方案:在 dispatch 里拦截 tool call name == "load_skill" · 成功后 insert

// agent_loop 里:
if resp.tool_calls.is_empty() {
    // 要 FINAL 了 · 先 check expected_outputs
    let missing = self.check_active_skills_outputs().await;
    if !missing.is_empty() && !self.final_forced {
        log::warn!("FAKE FINAL blocked · missing: {:?}", missing);
        messages.push(Message::user(format!(
            "你声明完成但产物缺失: {:?} · 继续调 tool 完成 · 不要 FINAL",
            missing
        )));
        self.final_forced = false;  // 允许再次尝试
        continue;
    }
    return Ok(...);  // 真 FINAL
}
```

**max_retry** = 3 (避免无限 retry loop)· 超了强制 stop 并在 stats 里标 `forced_stop_missing_outputs`。
