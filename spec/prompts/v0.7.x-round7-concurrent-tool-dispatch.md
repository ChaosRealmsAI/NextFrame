## 背景

Claude Code 一轮 chat 返多 tool_calls 时**并行**执行 read 类(Read / Grep / Glob)· 串行执行 write 类(Bash / Write / Edit)。当前 engine 所有 tool 串行跑 · model 多 tool_calls 时每个等前一个完 · 慢。

## 目标(通用)

1. **Tool trait 加 `concurrency_safe(&self) -> bool`** · 默认 false(保守)· 纯读 tools 覆盖为 true
2. **agent.rs dispatch 循环**:
   - 把本轮 tool_calls 按 safety 分两组
   - safe 组 `futures::future::join_all` 并发
   - unsafe 组串行
   - 合并保原顺序返回 tool messages
3. **内置 tool 标注**:
   - `BashTool` · false(side effects)
   - `ReadTool` · true(纯读)
   - `LoadSkillTool` · true(纯读 registry)
   - `VerifyOutputsTool` · true(纯读 filesystem glob)
4. **log::info** 记录并发度(如 `concurrent dispatch: 3 safe + 1 unsafe`)

## 变动文件

### 1. `crates/nf-agent/src/tool.rs`

```rust
#[async_trait]
pub trait Tool: Send + Sync {
    fn name(&self) -> &str;
    fn description(&self) -> &str;
    fn input_schema(&self) -> Value;
    async fn call(&self, args: Value) -> Result<Value>;
    fn concurrency_safe(&self) -> bool { false }  // default false
}

// 覆盖:
impl Tool for ReadTool { ... fn concurrency_safe(&self) -> bool { true } }
impl Tool for LoadSkillTool { ... fn concurrency_safe(&self) -> bool { true } }
impl Tool for VerifyOutputsTool { ... fn concurrency_safe(&self) -> bool { true } }
// BashTool 默认 false
```

### 2. `crates/nf-agent/src/agent.rs`

`run()` 里 dispatch 循环改并行:

```rust
// 分类
let mut safe_calls: Vec<(usize, &ToolCall)> = Vec::new();
let mut unsafe_calls: Vec<(usize, &ToolCall)> = Vec::new();
for (idx, tc) in resp.tool_calls.iter().enumerate() {
    let tool = self.tools.iter().find(|t| t.name() == tc.name);
    if tool.map(|t| t.concurrency_safe()).unwrap_or(false) {
        safe_calls.push((idx, tc));
    } else {
        unsafe_calls.push((idx, tc));
    }
}
log::info!("concurrent dispatch: {} safe + {} unsafe", safe_calls.len(), unsafe_calls.len());

// 并发 safe
let safe_futs = safe_calls.iter().map(|(idx, tc)| async move {
    let result = self.dispatch(tc).await;
    (*idx, tc.clone(), result)
});
let mut results = futures::future::join_all(safe_futs).await;

// 串行 unsafe(保原子序)
for (idx, tc) in &unsafe_calls {
    let result = self.dispatch(tc).await;
    results.push((*idx, (*tc).clone(), result));
}

// 回排
results.sort_by_key(|(i, _, _)| *i);
```

然后按 idx 顺序 push tool message + 追踪 active_skills。
